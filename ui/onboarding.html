AirGPT first-run setup

AirGPT, DMS, and OpenVault on this computer. The public tunnel stays off. The service token is stored and never shown.

  1. Install on this computer

    Install Python 3.11 or newer. In the AirGPT folder run pip install -r requirements.lock. On Windows that also installs pywin32. On Linux and macOS that line is skipped.

  2. Create the local service token

    Press the button below, or run python -m bundle.launch --check. The token goes to the OS keychain when that works, and to a file with mode 0600 so DMS and OpenVault can read it. It is not shown.

  3. Start AirGPT, DMS, and OpenVault

    Run python -m bundle.launch --up. AirGPT listens on http://127.0.0.1:8765. DMS listens on http://127.0.0.1:8011 when DMS_CMD is set. OpenVault listens on http://127.0.0.1:5000 when OPENVAULT_CMD is set.

  4. Set a passcode on this computer

    Open http://127.0.0.1:8765. In Settings, then Profile, set a host passcode before any phone joins.

  5. Leave the public tunnel off

    Public tunnel is off by default. Turning it on publishes this computer on the internet through cloudflared or another provider. Anyone with the URL can reach the sign-in page. Only continue if you accept that.

  6. Open the LAN only if you mean to

    The default bind is 127.0.0.1. Set AIRGPT_BIND=0.0.0.0 only when other machines on your network should connect. Startup prints a warning.
